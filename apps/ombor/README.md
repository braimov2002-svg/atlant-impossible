# Омбор бошқаруви — ООО «Atlant Construction»

Заявка, тўлов тасдиғи ва приходни юритадиган сайт. Телефонда (Android, iPhone)
ва компьютерда (Windows, macOS) браузерда очилади; иконка қилиб экранга
ўрнатиш мумкин (Меню → «Телефонга ўрнатиш»).

## Нима қилади

| Лавозим | Нима қила олади |
| --- | --- |
| **Бош омбор мудири** | Ҳамма нарса. Логин ва паролларни тарқатади, Excel’дан юклайди, ўчиради |
| **Омборчи** | Заявка яратади, келган материални приходга қабул қилади, приход журнали |
| **Снабженец** | Заявка яратади, тўлов сўрайди, тўланганини белгилайди |
| **Раҳбар** | Тўловни тасдиқлайди ёки рад этади, ҳисоботлар, объектлар |

Заявка йўли: **Жараёнда** → раҳбар тўловни тасдиқлайди → **Тўлов тасдиқланди**
→ омборчи приходга қабул қилади → **Қабул қилинди**.

Объектлар папка кўринишида: папкага кирсангиз, шу объектнинг заявкалари очилади.

## Интернетга чиқариш (бир марта, бепул)

1. [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) да бепул ҳисоб очинг.
2. Чапдаги менюдан **Workers & Pages** ни очинг. Биринчи киришда `…workers.dev`
   учун ном сўрайди — масалан `atlant`. Сайт манзили `ombor.atlant.workers.dev` бўлади.
3. Шу саҳифанинг ўнг томонидан **Account ID** ни нусхаланг.
4. [dash.cloudflare.com/profile/api-tokens](https://dash.cloudflare.com/profile/api-tokens) →
   **Create Token** → **Edit Cloudflare Workers** андозаси. «Account Resources»да
   ҳисобингизни танланг, сўнг **+ Add more** билан `Account → D1 → Edit` рухсатини
   қўшинг. **Create Token** — чиққан калитни нусхаланг (у бир марта кўрсатилади).
5. GitHub’да шу репозиторий → **Settings → Secrets and variables → Actions →
   New repository secret**. Иккита сир қўшинг:
   - `CLOUDFLARE_ACCOUNT_ID` — 3-қадамдаги ID
   - `CLOUDFLARE_API_TOKEN` — 4-қадамдаги калит
6. **Actions → Ombor deploy → Run workflow**. Бир-икки дақиқада сайт тайёр;
   манзил иш журналининг охирида чиқади.

Кейин `main` тармоғидаги `apps/ombor` ўзгарса, сайт ўзи янгиланади.

## Биринчи кириш

1. Сайтни очинг. Биринчи марта у **Бош омбор мудири** учун логин ва парол
   ўрнатишни сўрайди. Буни сайт чиққан заҳоти қилинг: биринчи кирган одам
   бошқарувчи бўлади.
2. **Меню → Excel’дан юклаш**: «АС материал» файлини танланг. «Приход» ва
   «заявка» саҳифалари юкланади. Буни компьютерда қилган маъқул. Файлни
   қайта юкласангиз, такрорий ёзув қўшилмайди.
3. **Меню → Логин ва пароллар**: ходимларга логин ва парол беринг.

Excel’дан юклашда «Код материала» устуни шундай ўқилади: `АС-…` ва «Балтон» —
битта объект (Балтон); `SHERON …` ва «Шерон» — битта объект (Шерон);
қолган ҳар бир ном — алоҳида объект. Рақамли кодлар (`АС-001-10-2025`,
`SHERON 004`) заявка бўлади. Бир объект икки хил ёзилган бўлса (масалан
«Боуржан» ва «Бауржан»), объект ичида **Таҳрирлаш → Бошқа объектга қўшиб
юбориш** орқали бирлаштирилади.

## Дастурчи учун

```bash
npm install
npm run build -w @atlant/ombor
cd apps/ombor && npx wrangler d1 migrations apply ombor --local && npx wrangler dev
```

- `src/server` — Hono API (Cloudflare Worker), маълумотлар D1 (SQLite) да.
- `src/client` — React. Excel’ни браузернинг ўзи ўқийди (`xlsx.ts`, `workbook.ts`).
- Тестлар: `npx vitest run apps/ombor` (API локал D1 базасида текширилади).
- Компания маълумотлари репозиторийга қўшилмайди — улар сайт орқали юкланади.
