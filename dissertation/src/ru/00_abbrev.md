# СПИСОК СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ

| Сокращение / обозначение | Значение |
|:---|:---|
| AAPM | Американская ассоциация физиков в медицине |
| AgNP | наночастица серебра |
| ALARA | настолько низко, насколько это разумно достижимо |
| AuNP | наночастица золота |
| BH-E | нерелятивистское сечение тормозного излучения Бете–Гайтлера с множителем Эльверта |
| ЭЗЧ | электронное (зарядовое) равновесие |
| CSDA | приближение непрерывного замедления |
| DEF | коэффициент усиления дозы |
| РМ | разработанная модель (полуаналитическая модель спектра рентгеновского излучения, предложенная в данной работе) |
| ДНК | дезоксирибонуклеиновая кислота |
| СПО | слой половинного ослабления (СПО1 и СПО2 — первый и второй слои половинного ослабления) |
| МАГАТЭ | Международное агентство по атомной энергии |
| МКРЕ | Международная комиссия по радиационным единицам и измерениям |
| МЭК | Международная электротехническая комиссия |
| кВп | киловольт пиковый (пиковое напряжение на рентгеновской трубке) |
| МК | (метод) Монте-Карло |
| NIST | Национальный институт стандартов и технологий (США) |
| АФК | активные формы кислорода |
| ЛТ | лучевая терапия |
| SER | коэффициент сенсибилизации |
| TASMIP | модель спектра вольфрамового анода на основе интерполяционных полиномов |
| TBC | модель спектра Tucker–Barnes–Chakraborty |
| $D$ | поглощённая доза, Гр |
| $E$ | энергия фотона, кэВ |
| $\bar{E}$ | средняя энергия фотонов спектра, кэВ |
| $E_K$ | энергия связи K-оболочки (энергия K-края поглощения), кэВ |
| $K$ | керма (кинетическая энергия, высвобожденная в единице массы), Гр; $K_{\mathrm{air}}$ — воздушная керма |
| $R(E)$, $\langle R\rangle$ | отношение $\mu_{en}/\rho$ серебра к $\mu_{en}/\rho$ ткани при энергии $E$; его спектральное среднее, взвешенное по дозе |
| K$\alpha$, K$\beta$ | характеристические линии K-серии (переходы на K-оболочку с L-оболочки и с M- и N-оболочек соответственно) |
| $S(T)$ | ионизационная тормозная способность материала анода для электрона с кинетической энергией $T$; $S/\rho$ — массовая ионизационная тормозная способность, МэВ·см$^2$/г |
| $T$ | кинетическая энергия электрона, кэВ |
| $T_0$ | начальная кинетическая энергия электронов на аноде, $T_0 = eU$ (максимальная энергия фотонов), кэВ |
| $U$ | напряжение на трубке, кВ |
| $w$ | массовая доля серебра (или другого элемента с высоким Z) в ткани |
| $Z$ | атомный номер |
| $\eta$ | коэффициент глубины проникновения электронов, единственный подгоночный параметр РМ |
| $\theta$ | угол анода (угол между поверхностью анода и центральным лучом пучка) |
| $\mu$ | линейный коэффициент ослабления, см$^{-1}$ |
| $\mu/\rho$ | массовый коэффициент ослабления, см$^2$/г ($\rho$ — плотность) |
| $\mu_{en}/\rho$ | массовый коэффициент поглощения энергии, см$^2$/г |
| $\sigma_K$ | сечение ионизации K-оболочки электронным ударом, б |
| $\Phi(E)$ | спектральный флюенс фотонов (флюенс фотонов на единичный интервал энергии) |
| $\Psi(E)$ | спектральный флюенс энергии, $\Psi(E) = E\,\Phi(E)$ |
| $\omega_K$ | выход флуоресценции K-оболочки |
